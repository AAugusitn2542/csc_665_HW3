Question 2:

Let C = A's answer is correct, and Y = B replies "yes."

Given: P(C) = 1/3, P(Cᶜ) = 2/3. B is correct with probability 1/3, independent of A.

Likelihoods:

If C is true, the truthful answer is "yes," so B says yes when B is correct: P(Y | C) = 1/3
If C is false, the truthful answer is "no," so B says yes when B is wrong: P(Y | Cᶜ) = 2/3

Total probability of a "yes":

P(Y) = P(Y | C)P(C) + P(Y | Cᶜ)P(Cᶜ) = (1/3)(1/3) + (2/3)(2/3) = 1/9 + 4/9 = 5/9

Bayes' rule:

P(C | Y) = P(Y | C)P(C) / P(Y) = (1/9) / (5/9) = 1/5
